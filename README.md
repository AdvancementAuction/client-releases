# Advancement Battle

Race other players to complete Minecraft advancements.

**[Download](https://github.com/AdvancementAuction/client-releases/releases)**

The current download is a test build. Automatic updates are not enabled yet.

## Install

1. Install [Prism Launcher](https://prismlauncher.org/download/) and sign in with your Minecraft account.
2. Download the `.mrpack` file from a release.
3. In Prism, choose **Add Instance → Import**, select the file, and launch. Use Java 25.

Download the `.mrpack`, not GitHub's **Source code** archives.
