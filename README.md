# Advancement Battle

Race other players to complete Minecraft advancements.

**[Download the dev playtest](https://github.com/AdvancementAuction/client-releases/releases/tag/v0.0.78-dev.1)**

Requires beta access in the **AB - Dev** Discord server.

## Install

1. Install [Prism Launcher](https://prismlauncher.org/download/) and sign in with your Minecraft account.
2. Download **advancement-battles-dev.mrpack** from the release.
3. In Prism, choose **Add Instance → Import**, select the file, and launch. Use Java 25.
4. Follow **Link Minecraft** in the game to link your Discord account.

Automatic updates are not enabled for this playtest.
